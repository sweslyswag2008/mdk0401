# ПР4 — Авторизация (десктоп), «Библиотека»

Окно входа для сотрудников библиотеки на Python (tkinter): логин, пароль,
показ пароля, ограничение в 3 попытки, хранение пароля в виде SHA-256.

## Запуск
```
python autorize.py
```
Тестовые учётные данные: `admin` / `lib2026` (Администратор), `librarian` / `books123` (Библиотекарь).
Tkinter входит в стандартную поставку Python для Windows — ничего ставить не нужно.
